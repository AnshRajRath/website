🔩 SCARA Robot Kinematics & Control

The SCARA (Selective Compliance Assembly Robot Arm) robot is designed for fast and precise assembly line tasks. It features two rotating joints, making it well-suited for waste sorting applications.

  • Forward Kinematics: Determines the position of the robotic arm’s end-effector.
  • Inverse Kinematics: Calculates joint angles to reach a specific point.
  • Trajectory Planning: Ensures smooth movement while avoiding obstacles.

📊 Hybrid Optimization for Trajectory Planning

The SCARA robot's movement is optimized using a Hybrid Genetic Algorithm (GA) and L-BFGS-B approach:

  • Genetic Algorithm (GA): Conducts a global search for optimal trajectories.
  • L-BFGS-B: Fine-tunes movements to enhance precision.
  • Singularity Avoidance: Uses Jacobian matrix analysis to prevent unstable positions.
  • Adaptive Mutation Strategies: Inspired by simulated annealing to escape local minima.

Results: This hybrid approach improves convergence speed by 80% and reduces computational overhead.

🖼️ AI-Based Waste Classification & Image Processing
