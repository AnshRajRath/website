# AI-Powered Waste Segregation Robot

An educational web project presenting an AI and robotics approach to automated waste segregation for smarter waste management.

## Overview

The project explains a waste-sorting system that combines computer vision, AI-based classification, SCARA-style robotic handling, and trajectory optimization. The repository itself is a multi-page informational website built with HTML, CSS, and JavaScript.

## Pages

- `home.html` — project overview and motivation
- `introduction.html` — background and problem statement
- `theory.html` — technical concepts
- `examples.html` — examples and use cases
- `conclusion.html` — project conclusions

## Tech stack

- HTML5
- CSS3
- JavaScript

## Run locally

Clone the repository and open `home.html` in a browser.

```bash
git clone https://github.com/AnshRajRath/website.git
cd website
```

For a simple local web server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/home.html`.
